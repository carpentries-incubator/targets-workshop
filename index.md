This is a lesson about how to use the [targets](https://docs.ropensci.org/targets/) R package for maintaining efficient data analysis workflows.


:::::::::::::::::::::::::::::::::::::: prereq

## Prerequisites

This lesson assumes moderate proficiency in R. Learners should be familiar with:

- The [R programming language](https://www.r-project.org/), as covered in [R for Data Science](https://r4ds.hadley.nz/)
- [Data science workflow management techniques](https://rstats.wtf/)
- [How to write functions](https://r4ds.hadley.nz/functions.html) to prepare data, analyze data, and summarize results in a data analysis project
